# 内置 OIAPI 酷我音源

[oiapi-kuwo.js](../app/src/main/assets/script/oiapi-kuwo.js) 是随应用打包的 LX 音源脚本，仅支持酷我平台的 128 / 320 kbps MP3，不需要账号或 API 密钥。也可作为独立脚本导入其他兼容的 LX 客户端。

在应用「设置 → 自定义音源」中选择 OIAPI 酷我，在在线搜索中选择酷我结果。播放音质设为 320 kbps；下载时选择 320 kbps。应用若开启了自动降低播放音质，播放失败后仍可能再次请求 128 kbps；需要固定 320 时请关闭该选项。下载会保留所选音质。升级仅补充新增音源，保留原有选择、停用状态和已删除的旧音源；删除 OIAPI 后再次启动也不会自动加回。

脚本按酷我歌曲编号匹配版本，从接口返回的 `types` 列表计算 `br` 参数，校验返回的歌曲编号、MP3 格式和码率。接口返回其他码率时抛出错误，不把低码率链接当成 320 返回。对实时音频文件的编码码率校验属于下述诊断实测，脚本自身依赖接口元数据。

## 2026-11-13 排查记录

- 内置野花脚本对五个平台均只声明 `128k`。当日获取的上游最新脚本与内置文件 SHA-256 相同，因此更新同一脚本不能增加 320 支持。
- 搜索到 [GD Studio 适配脚本](https://github.com/wangxanshen/lx-music-source)、[Allone](https://github.com/nkolp/Sound-source-for-all/releases/tag/1.0.1) 和[墨澜](https://github.com/baiji6/molanyinyueyuan) 等声称支持 320 的候选。GD 脚本会在 320 失败后尝试 128；墨澜最新脚本经过混淆，未执行验证。
- 使用《茶花开了》—王睿卓进行核对：GD 的网易搜索成功，320 / 128 取链接口均返回 HTTP 403；Allone 的网易公开接口返回 128 kbps，备用接口发生 TLS 连接错误。
- Allone 的酷我适配把 320 映射成固定的 `br=5`，该例返回 128 kbps。OIAPI 的 `br` 实际表示该歌曲音质列表中的序号，不同歌曲的顺序可能不同；该例的 320 MP3 位于第 2 项。
- 根据[接口提供方文档](https://oiapi.net/index/doc?id=79)和实时返回的列表请求 `br=2` 后，歌曲编号为 `442087398`，接口返回 320 kbps MP3；音频服务器返回 HTTP 206、总长度 10,802,282 字节。只读取前 128 KiB，解析到连续 8 个 MPEG Layer III 音频帧均为 320 kbps / 44.1 kHz，未下载整首歌。
- 在 Node 沙箱加载应用原有 `user-api-preload.js` 后，脚本通过 8 项行为检查（包含音质顺序变化、低码率替代、版本变化及 HTTP 失败），以及该歌曲 320 / 128 的 2 项联网取链检查。没有增加应用构建依赖。

## 0.9.16 盒子验证

已在 YYA-H618（Android 12 / ARMv7）使用同签名正式包从 0.9.14 覆盖升级至 0.9.16，保留原应用数据。通过实际 `PlaybackService` 和 `Downloads` 验证《茶花开了》—王睿卓：

- 关闭自动降低音质，选择内置 OIAPI 酷我和 320k，实际播放器解码格式为 320,000 bit/s / 44.1 kHz，播放进度从 0 推进至 6,010 ms，没有播放错误。
- 应用下载任务完成，下载页显示 100%、下载完成、320K；文件位于 `Download/LX Music/`，总长 10,802,282 字节，时长 270,027 ms。
- Android MediaExtractor 读取下载文件码率为 320,000 bit/s；拉取设备实际文件核对 SHA-256，并顺序扫描全部 10,338 个 MP3 帧，均为 320 kbps / 44.1 kHz。
- 文件 SHA-256：`72bee22ac28b0d2b264b99525726a3277494ffacc3c2af6ac8164bc17c968414`。

首次盒子联网测试遇到一次域名解析失败；检查时域名解析和网络连通已恢复，未修改系统 DNS，随后原生取链及实际播放、完整下载通过。验证结束保留新音源和 320k 设置，关闭自动降质，播放暂停，下载文件保留。

该结果确认这首歌在验证时可以播放和完整下载 320 kbps 编码文件，不代表全曲库或长期可用。脚本适配第三方公共服务，没有自建音乐后端。接口提供方将服务限定为免费、非商业用途，详见其[使用协议](https://oiapi.net/agreement)。
